# Third-party software

BambooShift's original source is licensed under the [MIT License](LICENSE). Third-party dependencies retain their own licenses. The project is independently developed and is not affiliated with or endorsed by xAI or Grok.

The npm, Cargo and Flutter lockfiles identify the exact dependency versions. Installing those dependencies brings their license files; keep those files when redistributing a service or client. In particular, do not remove dependency notices from `node_modules`, the Electron runtime, or the Chromium distribution used by the computer worker.

The service packager inventories the dependencies compiled into the Rust executables and actually rendered into the two web bundles. It includes their original license texts and a `third-party/index.json` inventory, and fails when a required notice is missing. Separately installed workers and optional execution-host packages must retain the notices installed with their dependencies. Version-specific supplements in `legal/third-party` preserve original upstream notices omitted from locked package publications.

Desktop packages built with `--with-runtime` also install the locked production worker dependencies and include their original texts in `bambooshift-runtime/runtime-notices`, alongside the dependency files in `runtime/node_modules`. The official Node distribution's complete bundled license text is retained as `bin/LICENSE`. The macOS package includes the MIT standalone Cua Driver 0.47.8 executable and its original notice at `licenses/CuaDriver-LICENSE.md`; it does not include Cua's optional N-API SDK artifacts, Spaces, Bench, or perception models. Node and Cua downloads are checked against their distribution hashes before extraction. The project's MIT license does not replace dependency licenses: for example, the MCP client and Sharp wrapper declare Apache-2.0, and Sharp's bundled libvips package declares LGPL-3.0-or-later. The inventories preserve the corresponding original notices.

The managed desktop runtime is a development preview and is not yet enabled in release builds. Its native dependency notice and corresponding-source review is incomplete; collected inventories alone do not satisfy every constituent's redistribution terms. The strict package build remains blocked until those materials and packaged acceptance are complete.

The managed desktop runtime does not bundle a separate Chrome installation. The independent browser requires Chrome on its execution computer; preserve that distribution's own notices when providing it separately. Windows releases currently contain a connection client only. Same-platform macOS/Linux runtime packaging does not imply Windows local execution or Linux host desktop support.

The Android Gradle wrapper is distributed under Apache-2.0; see [Gradle's license](https://github.com/gradle/gradle/blob/master/LICENSE). Flutter platform scaffolding is generated by Flutter and uses the Flutter project's license. The avatar body artwork and application UI in this repository are original BambooShift assets; selected eye-animation parameters and interpolation helpers are adapted from BoopFace as described below. The source release includes reviewed first-party demos. Third-party reference screenshots and videos are excluded.

## BoopFace eye animation

The avatar eye poses, easing/interpolation helpers, and time-weighted gaze smoothing include adaptations from [BoopFace 0.8.0](https://github.com/CX-ArtLab/BoopFace/tree/24ee5f698e58fa4f131b5ae7827373814e191f4c), by CX ART Lab, at commit `24ee5f698e58fa4f131b5ae7827373814e191f4c`. The selected sources are `src/boopface-core.js` and `embedded/lib/BoopFace/src/BoopFaceGaze.h`. BambooShift converts these parameters for its own artwork and renders them in its Web and Flutter clients; the upstream robot body and full component runtime are not included. ## Other separately licensed assets

The Flutter web client bundles a Chinese web font derived from [Noto Sans SC 2.004](https://github.com/google/fonts/tree/2894aab31764f10f29c421bdfd2340d3b382d384/ofl/notosanssc). Copyright 2014–2021 Adobe, with Reserved Font Name “Source.” The [SIL Open Font License 1.1](mobile/assets/fonts/OFL-NotoSansSC.txt) accompanies the font in the web build. The renamed WOFF2 uses a static regular weight and preserves all 30,890 character mappings from the upstream regional font. Native builds use the platform font fallback and omit this asset.

To reproduce the asset, use `scripts/build-mobile-cjk-font.py` with FontTools 4.56.0 and Brotli 1.1.0. The upstream TTF SHA-256 is `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`. The derived WOFF2 SHA-256 is `0d6e18f5cbe80a66b84387319e54db11af960fa671857ac16cf9cf51036adf54`.

Release builders are responsible for checking the licenses of their optional model weights, speech models, system packages and connectors. These are configured or installed separately, not bundled with the BambooShift source export. A model API key does not grant redistribution rights to that model.
