# Third-party software

OpenBot's original source is licensed under Apache-2.0. Third-party dependencies retain their own licenses. The project is independently developed and is not affiliated with or endorsed by xAI or Grok.

The npm, Cargo and Flutter lockfiles identify the exact dependency versions. Installing those dependencies brings their license files; keep those files when redistributing a service or client. In particular, do not remove dependency notices from `node_modules`, the Electron runtime, or the Chromium distribution used by the computer worker.

The service packager inventories the dependencies compiled into the Rust executables and actually rendered into the two web bundles. It includes their original license texts and a `third-party/index.json` inventory, and fails when a required notice is missing. The inventory does not describe separately installed SDK workers or optional execution-host packages; those deployments must retain the notices installed with their dependencies. The version-specific supplements in `legal/third-party` preserve original upstream notices omitted from two published Rust source archives.

The Android Gradle wrapper is distributed under Apache-2.0; see [Gradle's license](https://github.com/gradle/gradle/blob/master/LICENSE). Flutter platform scaffolding is generated by Flutter and uses the Flutter project's license. The SVG avatar artwork and application UI in this repository are original OpenBot assets. Reference screenshots and video media are not included in the source release.

The Flutter web client bundles **OpenBot Sans SC**, derived from [Noto Sans SC 2.004](https://github.com/google/fonts/tree/2894aab31764f10f29c421bdfd2340d3b382d384/ofl/notosanssc). Copyright 2014–2021 Adobe, with Reserved Font Name “Source.” The [SIL Open Font License 1.1](mobile/assets/fonts/OFL-NotoSansSC.txt) accompanies the font in the web build. The renamed WOFF2 uses a static regular weight and preserves all 30,890 character mappings from the upstream regional font. Native builds use the platform font fallback and omit this asset.

To reproduce the asset, use `scripts/build-mobile-cjk-font.py` with FontTools 4.56.0 and Brotli 1.1.0. The upstream TTF SHA-256 is `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`. The derived WOFF2 SHA-256 is `0d6e18f5cbe80a66b84387319e54db11af960fa671857ac16cf9cf51036adf54`.

Release builders are responsible for checking the licenses of their optional model weights, speech models, system packages and connectors. These are configured or installed separately, not bundled with the OpenBot source export. A model API key does not grant redistribution rights to that model.
