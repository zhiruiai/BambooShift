# 打开输出文件

在网页或桌面客户端里，从聊天、资料库或电脑传输结果点文件卡片即可预览。弹框顶部固定文件名、下载和关闭操作，正文单独滚动。预览失败、文件太大或格式不支持时，仍可下载原件打开。

| 文件 | 预览内容 |
| --- | --- |
| HTML、HTM | 保留允许的样式、渐变和 SVG 图形。支持识别出的章节切换、展开、图示说明、分步演示和答题，并提供源码切换。朗读需要可用的本地声线。 |
| PDF | 按页显示原有版式，可上一页、下一页。受密码保护、损坏或超过 200 页时可下载。 |
| DOCX、XLSX、PPTX | 查看 Word 段落和表格、Excel 工作表、PowerPoint 幻灯片文字。需要完整排版、公式计算或播放动画时使用原件。 |
| CSV、TSV | 表格与原文切换。大表仅显示前 200 行、最多 48 列，界面会提示截断。 |
| PNG、JPEG、WebP、GIF | 图片预览。 |
| MP3、WAV、M4A、Ogg、Opus、FLAC、MP4、WebM、OGV | 使用当前客户端支持的解码器播放，点击播放后才开始。 |
| Markdown | 默认按标题、列表、表格和代码排版，可切换源码。链接和图片显示为文字。 |
| JSON、日志、常见源代码与配置文本 | 可选中文字的原文预览。 |
| 其他文件 | 下载后使用对应应用打开，包括旧版 Office 和通用压缩包。 |

文本、表格、HTML 和图片预览最多读取 2 MiB；PDF、Office 和媒体最多读取 10 MiB。下载与预览走已登记文件的固定接口，原始内容不会被改写。手机端的原生客户端可查看文本、HTML 源码与图片，并可通过系统界面保存或分享原件。

`web/src/filePreview.ts` 负责同空间下载授权、响应类型与大小校验、取消请求和临时地址回收。`FormattedFilePreview` 将内容交给相应的渲染器；PDF 仅使用本机资源，Office 只展示已提取的结构和文字。HTML 文件本身的脚本、网络资源、链接和表单会被移除。可识别的控件由 PandaMate 自己的代码处理，运行在与聊天页面隔离的 iframe 中；其他原始网页行为仍以下载原件为准。
