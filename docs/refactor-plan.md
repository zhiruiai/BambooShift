## 实施边界

- `server/api/src`：Rust 平台、空间领域与执行编排，按模块独立测试。
- `server/workers/pi-worker`：无业务数据库写入的 Pi 执行协议与会话。
- `web/src`：React 视图、控制器、公共组件、语言资源和主题。
- `desktop`：Electron 薄客户端与平台权限桥。
- `mobile`：Flutter 客户端，使用同一 Rust 服务。
- `shared`：现有接口契约；后续用统一 schema 派生客户端类型，避免三端手工漂移。

正式数据与模型凭据保留，备份及部署配置维持私有。运营初始化码只允许检查存在，不读取。实际 GUI 验收使用经授权的虚构账户和合成资料，不以既有用户正文、附件或私人数据作为测试输入。
