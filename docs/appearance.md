# 外观与拼写偏好

「设置 → 通用 → 外观偏好」提供主题、强调色、语言、拼写检查和原创头像主题，调整后立即在当前页面生效。默认值是跟随系统、Bot 颜色、开启拼写检查。这些是设备上的显示与输入偏好，不修改 Bot 资料、账号权限或工作任务。

## 外观

外观可选「跟随系统」「浅色」「深色」。跟随系统时，系统明暗模式变化会更新页面；明确选择浅色或深色后不再随系统变化。浏览器原生表单控件也使用相应的明暗模式。主题与语言分别保存；同一设置页提供中文、英文选择器。语言切换不翻译用户消息、记忆、长期指令或第三方原文，也不改变服务器模型配置。

强调色可选「Bot 颜色」或「黑白」。它只作用于真实一对一 Bot 会话中助手消息内容及卡片的装饰强调，包括气泡、引用、文件和操作卡片的相应外框或标题。头像原色、群聊中用于区分成员的 Bot 本色、用户发送的消息以及错误或审批状态的语义保持独立。选择黑白不修改 Bot 保存的颜色，切回 Bot 颜色即可继续使用。

电脑截图和历史操作画面保持原始颜色，不通过滤镜改变内容；也不会把外观设置发送给远程电脑，替用户修改远程桌面或应用的主题。

## 拼写检查

拼写开关控制页面的 HTML 拼写检查偏好。桌面与手机使用同一个聊天输入框，该输入框显式跟随开关；其他未指定该属性的字段按 HTML 规则继承，已有明确关闭拼写检查的搜索、路径或凭据字段保持关闭。切换不会清除草稿、发送消息，也不改变中文输入法合成、语音插入或回复对象。

桌面客户端仅为连接后的产品页面启用原生拼写服务，让页面和输入框的开关实际生效；本地连接设置页及通用渲染器的默认值仍为关闭。这个调整不开放 Node.js、页面脚本系统权限或其他浏览器权限。是否能提供某种语言的标记及纠错，仍取决于浏览器、Electron 所在系统和可用字典，不保证中文或所有语言都有纠错建议；它也不是由工作模型执行的语法检查。

## 保存范围

偏好以版本 1 的记录保存在当前浏览器或客户端的 `localStorage` 中，不写入个人或团队数据库，也不通过账号同步到其他设备。同一浏览器配置、同一服务地址来源下的窗口通过 `storage` 事件同步；切换账号不会把这份设备偏好变成另一个账号的服务端设置。另一个浏览器、不同来源的服务地址和另一台设备有各自的保存范围。

浏览器拒绝本地存储时，本页仍应用所选外观，并提示「暂时无法保存到此设备，本页调整仍然有效」。这种情况下不能保证刷新后保留选择。缺失、损坏或不支持的存储版本回到默认偏好。

## 验收边界

桌面策略测试检查了实际构造产品页面、连接设置页和重试页面时传入的拼写参数，并保留原有隔离选项。它不等同于启动真实桌面窗口验证字典或拼写提示。该阶段配置与事件测试不能单独证明视觉效果；其后页面验收范围见[验收记录](verification.md)。

视觉验收应覆盖浅色和深色下的聊天、设置、弹窗、菜单及卡片可读性；确认系统模式切换、同来源多窗口同步和存储不可用提示；检查一对一强调色不影响群聊、头像、错误状态或截图，并在浏览器与桌面客户端分别核对输入法、已有草稿和可用语言的拼写表现。
