# 例行任务的精确只读应用授权

空间拥有者可在“连接应用”的具体连接中，为一个已经保存并启用的本地 Bot 例行任务选择一个工具，查看实际说明和参数结构，输入固定 JSON 参数，并明确确认该服务和工具只读取所选资料。这是可撤销的单项授权；默认没有授权，不会根据模型文本、服务说明或只读注解自动创建授权。

首次版本只匹配完全相同的参数对象。例如 `{"query":"newer_than:1d"}` 可在每次计划触发时读取相对最近一天的资料；改变为另一查询范围时仍需人工审批。对象字段顺序不影响匹配，数组顺序和值必须相同，没有通配或自动扩展范围。

只有真正由服务器计划触发的根任务能使用预授权，并且当前空间拥有者必须仍是授权签发者。普通聊天、手动“立即运行”、成员请求、委派子任务、共享 Bot 和发布者来源应用继续沿原逐次审批流程。具有 `readOnlyHint: true` 且没有明确 `destructiveHint: true` 的工具才出现在可选名单中；这些注解只是候选条件，不能证明服务没有副作用。未知工具、写入工具或矛盾声明不允许预授权。

授权固定任务的七项配置、连接版本、来源认证范围、完整工具目录、工具定义和精确参数。修改或删除任务、重连/换账号/重新 OAuth 授权、改变工具说明或参数结构都会使原授权永久失效，即使随后恢复旧配置也需要重新确认。计划的 `nextRunAt`、`lastRunAt` 变化不影响授权。同一 OAuth 授权正常刷新令牌且主体与范围不变时保留授权；刷新失败或范围变化不能继续使用。

真正调用前重新获取远端目录，核对整个已确认目录，并再次验证原授权。每次自动批准仍写入普通应用操作卡，保存授权签发人、例行任务、完整参数和实际结果。相同计划运行中的同一连接/工具/参数只创建一个持久执行回执；结果未知、取消或服务重启均不自动重发。执行后撤销授权会拒绝迟到成功结果，但无法撤回外部已经发生的操作。

授权面板将恢复编号保存在当前设备的会话存储中，不保存参数或凭据。创建响应不确定时禁止新建，关闭重开后只读取原结果；用户可明确取消原编号，已接纳的授权会撤销，尚未到达的请求会被持久栅栏拒绝。存储不可用时禁止新建授权。所有管理请求固定原账号、空间和页面路径，并要求拥有者身份与 `X-OpenBot-Expected-User`；切换账号后旧按钮和迟到响应失效。

Rust 实现位于 `server/api/src/apps/policies.rs`、`policy_runtime.rs`、`policy_data.rs` 与 `action_execution.rs`，没有另起一套工具执行器。工作空间数据库只增加授权及执行编号表，不复制来源密钥。API 位于 `/api/workspaces/:workspaceId/apps/:connectionId/policies`：`GET` 列表、`GET /options` 当前真实候选、`POST` 明确确认、`POST /:policyId/revoke` 撤销或封闭未知请求。读取与写入均只允许当前空间拥有者。

验证使用临时 SQLite、真实 Pi 协议、本机合成模型和 MCP/OAuth 服务，覆盖计划实际调用、人工审批保留、换拥有者、配置与目录变化、刷新、重授权、执行中撤销以及重启。Web 使用生产组件和事件处理函数验证双语、精确确认、未知恢复和账号隔离。没有调用付费模型、访问真实第三方账号或操作正式服务；这些测试不替代产品 GUI 或第三方服务的验收。
