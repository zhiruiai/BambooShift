## 首次失败与修正

拆分后，主动跟进的一个运行测试成为新文件中首次加载 Pi SDK 的用例，原 500 ms 请求截止时间包含了首次模块加载，导致超时。修正为在测试套件开始时明确预加载 SDK；保留原截止时间、行为断言和用例正文。随后全服务回归通过。

首次 Chrome 补验发现纯执行包提取时遗漏了 `LocalComputer.captureDownload` 的兼容委托，原导出下载测试无法拦截该调用。补回薄委托后，原测试未改动，13 项 Chrome 检查全部通过。首次失败日志 `openbot-refactor-chrome-final.log` 保留，不将重跑结果表述为首轮全绿。
