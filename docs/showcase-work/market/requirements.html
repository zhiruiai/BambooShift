SQLite

SQLite 直接在应用进程内读写本地文件，部署时无需单独的数据库服务器进程。

Serverless ↗
SQLite

每个数据库文件同一时刻只有一个写入者。大量客户端同时通过网络直接读写同一数据库时，官方建议考虑客户端／服务端引擎。

When to use ↗
PostgreSQL

应用通过客户端连接数据库服务进程。服务器可以处理多个并发客户端连接。

Architecture ↗
PostgreSQL

MVCC 支持事务快照。在查询与普通写入之间，读写互不阻塞；相互冲突的写入仍可能等待。
