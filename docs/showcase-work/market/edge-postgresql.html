SQLite

推荐 SQLite

SQLite 以零配置嵌入式引擎运行在应用进程内，无需独立数据库服务进程，适合断网采样与轻量场景。边界：同一文件同时仅支持一个写入者，大量网络并发写入时需改用客户端/服务端架构。

评估应用规模→确认写入频率→选用 SQLite→嵌入应用进程→验证单写者边界
